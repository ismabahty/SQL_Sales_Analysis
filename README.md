  SQL Sales Analysis

---Project Overview
This project analyzes product, customer, and sales data using SQL.
The goal is to practice SQL queries and use data to answer common
business questions related to products, pricing, customers, and sales.

 ---Analysis
In this project, I explored:
- Product prices and categories
- Product colors and price ranges
- Customer orders
- Sales revenue by product
- Top-performing products
- Sales revenue by product category

---- SQL Skills Used
- SELECT and WHERE
- ORDER BY
- AND / OR
- BETWEEN and IN
- LIKE
- DISTINCT
- NULL values
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- JOINs
- Ranking products by sales revenue

      Tools
- SQL Server
- SQLPro Studio
